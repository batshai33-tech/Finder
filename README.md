# my-app

React + Vite 프로젝트

## 시작하기

```bash
npm install
npm run dev
```

## 폴더 구조

```
src/
├── components/
│   ├── common/
│   │   ├── Header.jsx
│   │   ├── Button.jsx
│   │   └── Input.jsx
│   └── item/
│       ├── ItemCard.jsx
│       ├── ItemList.jsx
│       └── SearchBar.jsx
├── pages/
│   ├── Auth/
│   │   └── Login.jsx
│   ├── Home/
│   │   └── Home.jsx
│   ├── Items/
│   │   └── ItemCreatePage.jsx
│   └── MyPage/
│       └── MyPage.jsx
├── App.jsx
├── main.jsx
├── App.css
└── index.css
```

## 추가된 패키지

- `react-router-dom` - 페이지 라우팅
- `axios` - API 통신
